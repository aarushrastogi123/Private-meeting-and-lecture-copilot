# Recall — Meeting & Lecture Copilot

Recall is a local-first meeting and lecture assistant. It transcribes recordings on your computer, then helps you review and keep track of what was said.

## What it can do

- Record audio with a browser microphone or upload an existing audio file.
- Transcribe speech locally with the multilingual Whisper `base` model through faster-whisper, using CPU int8 inference.
- Automatically detect the spoken language during transcription.
- Show transcript segments with timestamps.
- Clear the current transcript and reset its recap, action items, and search results without deleting saved sessions.
- Create a lightweight recap and suggest possible action items using text rules. These suggestions are not generated by an LLM and should be checked against the transcript.
- Search the transcript, save and reopen sessions in this browser, delete saved sessions, and download notes as a text file.

## Requirements

- Windows, macOS, or Linux
- Python 3.9 or newer (Python 3.13 has been used with current Windows wheels)
- Internet access to install the Python packages and download the Whisper model the first time
- A modern browser; microphone recording requires browser microphone permission

## Run locally on Windows

Open PowerShell in the project folder and run:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000). Keep the terminal open while using Recall. Stop the server by pressing **Ctrl+C** in that PowerShell window.

The first transcription downloads the Whisper model. Later transcriptions run locally without sending audio to a hosted AI service.

## Run locally on macOS or Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn server:app --host 127.0.0.1 --port 8000
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000). Stop the server with **Ctrl+C** in the terminal.

## Privacy and limitations

- The server listens on `127.0.0.1`, so this version is intended for use on the same computer. It is not currently deployed as a public website.
- Audio is uploaded from the browser to the local server for transcription, stored temporarily for inference, and deleted afterward.
- The app does not send audio to a hosted AI service. Internet access is needed for package installation and the first model download.
- Saved sessions are stored in this browser's `localStorage`. Browser storage is not encrypted and may be accessible to other people using the same browser profile.
- Recaps and action items are heuristic suggestions. They may miss or misclassify information; verify names, decisions, owners, and dates.
- Speaker diarization is not included. The transcript does not label speakers unless names are spoken aloud.
- Transcription quality and speed depend on the model, CPU, recording quality, language, and background noise.
- The upload limit is 100 MB. Supported formats include MP3, M4A, WAV, WebM, OGG, AAC, and FLAC.
